Saisissez les clés des processeurs à proposer, séparées par une virgule.

Clés disponibles (selon les extensions installées) :

  • sumup_embedded_checkout_SumUP — Carte bancaire (SumUp)
  • sumup_solo_checkout_SumUP — Terminal SumUp
  • sumup_qr_checkout_SumUP — QR Code SumUp
  • sumup_hybrid_checkout_SumUP — Terminal / QR SumUp
  • pay_later — Virement bancaire / Paiement différé
  • stancer_embedded_checkout_Stancer — Carte (Stancer)
  • stancer_hosted_checkout_Stancer — Stancer (redirect)
  • helloasso_hosted_checkout_helloasso — HelloAsso

Exemple avec deux options : sumup_embedded_checkout_SumUP,pay_later
